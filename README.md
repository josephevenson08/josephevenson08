## Why This Mix Works

My work isn’t just “tech stuff” in the abstract. It’s a mix of:

- practical utility
- systems thinking
- game-inspired creativity
- real-world problems I wanted solved
- security + networking curiosity
- backend and full-stack growth

A lot of the projects I build come from one of three places:
1. I wanted something and it didn’t exist
2. I saw a problem and wanted a cleaner solution
3. I was curious enough to build it just to learn how it works

That’s the thread running through the repo.
